# Prints do aplicativo

Coloque aqui as imagens usadas no README principal, com estes nomes:

| Arquivo | O que mostrar |
|---|---|
| `modo-completo.png` | Modo completo com as duas contas, de preferência com uma delas trabalhando (anel girando) |
| `compacto-horizontal.png` | Faixa do compacto horizontal |
| `compacto-vertical.png` | Coluna do compacto vertical |
| `uso-semanal-hover.png` | Compacto vertical com a dica de uso semanal aberta (mouse sobre um velocímetro) |
| `configuracoes.png` | Janela de configurações |
| `bandeja.png` | Ícone da bandeja com o menu aberto |

Dicas:
- **Recorte:** use a Ferramenta de Captura do Windows (`Win + Shift + S`) e recorte só o painel, com um pouco de fundo em volta.
- **Formato:** prefira PNG, com até uns 300 KB por imagem.
- **Nomes diferentes:** se usar outros nomes, ajuste os caminhos no `README.md` da raiz.
