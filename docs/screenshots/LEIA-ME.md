# Prints do aplicativo

Imagens usadas no README principal. Ao mudar o layout, substitua o arquivo mantendo o mesmo nome:

| Arquivo | O que mostrar |
|---|---|
| `modo-completo.png` | Modo completo com as duas contas, de preferência com uma delas trabalhando (anel girando) e uma sessão na faixa amarela ou vermelha |
| `compacto-horizontal.png` | Faixa do compacto horizontal, com as barras da sessão e da semana |
| `compacto-vertical.png` | Coluna do compacto vertical, com o arco interno do uso semanal visível |
| `uso-semanal-hover.png` | Compacto vertical com a dica de detalhes aberta (mouse sobre um velocímetro) |
| `configuracoes.png` | Janela de configurações inteira, incluindo Animação e Envio para API |
| `bandeja.png` | Ícone da bandeja com o menu aberto |

Dicas:
- **Recorte:** use a Ferramenta de Captura do Windows (`Win + Shift + S`) e recorte só o painel, com um pouco de fundo em volta.
- **Opacidade:** capture com o fundo a 100%, para o painel não misturar com o que está atrás.
- **Formato:** prefira PNG, com até uns 300 KB por imagem.
- **Nomes diferentes:** se usar outros nomes, ajuste os caminhos no `README.md` da raiz.
