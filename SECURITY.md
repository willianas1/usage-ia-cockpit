# Segurança

## Versões com suporte

Só a versão mais recente publicada em [Releases](../../releases) recebe correções de segurança.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública** para falhas de segurança: ela fica visível para todos antes da correção.

Reporte em privado pela aba **Security** do repositório → **Report a vulnerability**. Se preferir, envie um e-mail para willian.as.dot@gmail.com.

Inclua, se possível:

- a versão do app e do Windows;
- o que a falha permite fazer;
- os passos para reproduzir.

Você recebe uma resposta em até 7 dias. Quando a correção sair, a vulnerabilidade é descrita nas notas da release, com crédito a quem reportou, se a pessoa quiser.

## Downloads oficiais

Os únicos arquivos oficiais são os publicados na página de [Releases](../../releases) deste repositório, gerados pelo GitHub Actions a partir do código público. Cada release traz um `SHA256SUMS.txt` para conferir o arquivo baixado (veja [Conferir o arquivo baixado](README.md#conferir-o-arquivo-baixado)). Cópias obtidas em outros sites podem ter sido alteradas.
